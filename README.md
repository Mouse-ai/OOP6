### Пользовательская история 1. Создание и группировка объектов

1. Пользователь создаёт круг и прямоугольник.
2. Выделяет оба объекта с помощью множественного выбора.
3. Выполняет команду «Сгруппировать».
4. Объекты удаляются из основного контейнера и помещаются внутрь объекта `Group`.
5. Созданная группа помещается обратно в основной контейнер.
6. Пользователь перемещает группу и убеждается, что обе фигуры двигаются совместно и сохраняют взаимное расположение.

**Ожидаемый результат:** круг и прямоугольник ведут себя как один объект и не могут быть выбраны отдельно, пока находятся в группе.

### Пользовательская история 2. Создание вложенных групп

1. Пользователь создаёт круг и квадрат и объединяет их в группу `G1`.
2. Создаёт эллипс и треугольник и объединяет их в группу `G2`.
3. Выделяет группы `G1` и `G2`.
4. Объединяет их в новую группу `G3`.
5. Перемещает `G3` клавиатурой или мышью.

**Ожидаемый результат:** все четыре фигуры перемещаются совместно. Внутри `G3` сохраняется структура двух вложенных групп `G1` и `G2`. Группа не выходит за границы рабочей области.

### Пользовательская история 3. Совместное изменение объектов группы

1. Пользователь создаёт несколько фигур и объединяет их в группу.
2. Выделяет созданную группу.
3. Изменяет цвет группы.
4. Увеличивает и уменьшает размер группы.
5. Перемещает группу к границе рабочей области.

**Ожидаемый результат:** цвет изменяется одновременно у всех объектов группы. Размер всех входящих объектов изменяется совместно. Если изменение невозможно хотя бы для одного объекта или приводит к выходу за границы, операция не должна частично изменять группу.

### Пользовательская история 4. Сохранение и восстановление сложной структуры

1. Пользователь создаёт несколько фигур разных типов.
2. Изменяет их размеры, цвета и положения.
3. Создаёт две группы и объединяет их во вложенную группу.
4. Выбирает команду «Сохранить».
5. В стандартном диалоге выбирает имя текстового файла.
6. Удаляет созданные объекты из рабочей области.
7. Выбирает команду «Загрузить».
8. Указывает ранее сохранённый файл.

**Ожидаемый результат:** восстанавливаются типы объектов, координаты, размеры, цвета и структура вложенных групп. Содержимое проекта после загрузки соответствует состоянию на момент сохранения.

### Пользовательская история 5. Разгруппировка вложенной группы

1. Пользователь создаёт группу `G1`, состоящую из двух фигур.
2. Создаёт отдельную третью фигуру.
3. Объединяет `G1` и третью фигуру в группу `G2`.
4. Выделяет `G2` и выполняет команду «Разгруппировать».
5. Получает в основном контейнере группу `G1` и отдельную третью фигуру.
6. Выделяет `G1` и повторно выполняет команду «Разгруппировать».

**Ожидаемый результат:** первая операция удаляет только внешний уровень группировки. Внутренняя группа `G1` сохраняется. После второй операции её объекты также становятся самостоятельными объектами контейнера.
